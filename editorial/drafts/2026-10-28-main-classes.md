## Новый класс - Bartz

Добавлен класс **Bartz**.

| Характеристика | Значение |
| --- | --- |
| Раса | Высший эльф |
| Пол | Мужской |
| Стиль боя | Ближний физический |
| Роль | Разбойник |
| Оружие | Кинжал |

- Создание персонажей класса Bartz открывается **28 октября 2026 года в 20:00**.
- При экипировке сигиля Bartz преобразует его силой света в **«Сияющий кинжал»**.
- Bartz **не может использовать щиты**.
- Внешний вид верхней части брони зависит от ранга экипированного предмета.
- Доступно **4 причёски, 3 варианта лица и 3 варианта окраски**.

## Переработка создания персонажа

1. Создание персонажа разделено на два этапа: **«Выбор класса»** и **«Настройка внешности»**.
2. При выборе класса можно ориентироваться на **финальную профессию**. После выбора расы и пола отображаются доступные финальные профессии.
3. Если при создании персонажа выбрана финальная профессия, при последующей смене профессии в дереве отображается **только она**. У персонажей, созданных ранее, дерево отображается по прежним правилам.
